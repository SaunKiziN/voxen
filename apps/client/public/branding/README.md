# VOXEN branding placeholders

Temporary VOXEN brand assets live here while the final symbol, favicon, and
desktop icon are being prepared.

- `voxen-mark.svg` is the compact mark used for the browser favicon fallback.
- `voxen-logo.svg` is the default connect screen logo when a server has no
  custom logo.
- `../favicon.ico`, `../icon-192.png`, `../icon-512.png`, and
  `../../desktop/src-tauri/icons/icon.ico` are generated placeholders for app
  surfaces that require bitmap or icon formats.

Replace these files with the final VOXEN assets when the brand package is ready.
